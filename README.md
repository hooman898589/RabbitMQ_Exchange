# RabbitMQ PHP Examples

این پروژه شامل مثال‌هایی از Exchangeهای RabbitMQ است.

## مثال‌ها

- exchange_direct
    - ارسال پیام بر اساس Routing Key

- exchange_fanout
    - ارسال پیام برای تمام Queueها (Broadcast)

- exchange_topic
    - ارسال پیام با Pattern مانند user.* یا order.#

- exchange_dead
    - Dead Letter Exchange (DLX)
